Install notes — Mac
Open the DMG, drag PallettAi Studio into Applications, then open it. This build is code-signed but not notarized with Apple, so right-click the app in Applications → Open if macOS shows a security warning. Your projects live in the app's local storage — sign in to sync your plan and license across devices.
Install notes — Windows
Run the EXE, choose an install folder, done. The Windows build is new and not yet code-signed, so SmartScreen shows “Windows protected your PC” — click More info → Run anyway. Needs Windows 10 (1809+) or Windows 11, 64-bit. Use Help → Check for Updates to retry an update check manually.
v0.4.5 — What's new in Studio
It reads the sentence, not just the words
  • "Do not make it dark" used to switch your site to Midnight. "I don't like the editorial look" used to apply it. A message is now read for what it is — a request, a refusal, a question, praise — before anything is planned.
  • Scope is read as written: two named sections are both handled, "every section" means every section, and "but keep the words" is honoured instead of quietly dropped. A refusal gets alternatives, never the thing you just turned down.
Undo one change, and keep everything after it
  • The sentence you type is "put the colours back", not "undo one step". It now finds your most recent change to the colours and restores only that, so the work you did afterwards survives.
  • Because it works in paths rather than steps, either half of "make the hero punchier and switch to ocean" can be put back on its own.
Publish is a decision, not a button
  • Six failures only exist once a site is live, and every one is invisible until a visitor hits it: two pages exporting to the same file, a menu link to a page that was never made, an enquiry with nowhere to go.
  • Also an insecure destination, a description left blank, and nothing to publish at all. The button now stops with the reason, rather than letting a stranger find it first.
Sites that keep working once you have moved on
  • A new audit asks what no other one asks — is this still true? Placeholder copy never filled in, our own sample address, an event date that has passed, last year's price beside your money, # links, images with no alt text.
  • Animated backgrounds that bind to your palette and honour motion settings, a free-tier badge carrying your own referral link so every site you sell recruits for you — and 7 free AI credits instead of 3.
Billing moved to Dodo Payments
  • Stripe's payment links carried your account id in a query string anyone could edit, so Pro could be bought for — or as — somebody else. Checkout now reads your account from your verified sign-in, and nothing is granted until the webhook verifies Dodo's signature.
